# SSE Market API 开放平台文档

欢迎使用 **SSE Market API 开放平台**（控制台：https://platform.ssemarket.cn）。

本平台提供与 **OpenAI 兼容** 的 Chat Completions 接口，底层对接学院 vLLM 等推理服务。你在控制台创建 API Key、查看模型与单价、管理余额与用量；对外调用统一走 API 域名，由平台转发并按 token（及可选图片）计费。

## 基本信息

| 参数 | 值 |
| --- | --- |
| 控制台 | `https://platform.ssemarket.cn` |
| API Base URL（OpenAI 兼容） | `https://api.ssemarket.cn/v1` |
| API Key | 登录控制台 → **API 密钥** → 创建 |
| model | 控制台 **模型** 页中的 **Slug**（例如 `qwen3.8-27b-awq`） |

> 调用时 `model` 必须填平台 Slug，不是上游 vLLM 内部 served-model-name。

## 最短示例

```bash
export SSEAPI_KEY="sk-你的密钥"
curl https://api.ssemarket.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $SSEAPI_KEY" \
  -d '{
    "model": "qwen3.8-27b-awq",
    "messages": [
      {"role": "user", "content": "你好，请用一句话介绍你自己。"}
    ],
    "max_tokens": 128,
    "chat_template_kwargs": {"enable_thinking": false}
  }'
```

文档风格参考行业常见 OpenAI / DeepSeek API Docs 结构，并结合本平台实际能力整理。价格以控制台模型卡片为准，可能随时调整。
