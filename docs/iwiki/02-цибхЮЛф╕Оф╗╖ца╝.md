# 模型与价格

下表价格单位为 **¥ / 百万 tokens（1M tokens）**，以控制台 **模型** 页展示为准（管理员可随时调整）。Token 是模型表示自然语言的最小单位；计费按实际用量结算。

## 如何查看可用模型

1. 登录控制台 → **模型**
2. 卡片上显示：展示名称、Slug（调用时的 `model`）、输入 / 缓存 / 输出单价、是否多模态等
3. 也可用 API：`GET /v1/models`（需 API Key）

## 示例：当前常见模型

> 下列数字为文档撰写时的示例，**请以控制台实时价格为准**。

| 项目 | 说明 |
| --- | --- |
| 展示名 | Qwen3.8-27B-AWQ |
| model（Slug） | `qwen3.8-27b-awq` |
| 能力 | 文本对话；开启多模态后支持图像理解（URL / Base64） |
| 输入（未命中缓存） | ¥1 / 1M |
| 缓存命中 | ¥0.001 / 1M |
| 输出 | ¥2 / 1M |
| 图片（若开启，按 token） | ¥0.01 / 1M（或按张计费，见管理台配置） |

## 价格字段含义

| 功能 | 对应 usage | 单价字段 |
| --- | --- | --- |
| 输入 tokens（未命中缓存） | `prompt_tokens - cached_tokens` | 输入价 ¥/1M |
| 缓存命中 tokens | `prompt_tokens_details.cached_tokens` | 缓存价 ¥/1M |
| 输出 tokens | `completion_tokens` | 输出价 ¥/1M |
| 图片 | 见 [计费说明](./计费说明) / [多模态](./多模态图像理解) | 图片价 |

缓存价支持细粒度配置（例如 `0.001`）。

## 扣费规则摘要

```
费用（元）≈ (未命中输入 × 输入价 + 缓存命中 × 缓存价 + 输出 × 输出价) / 1e6
         + 图片附加费（若按张）
```

平台以「分」为单位向上取整入账。余额不足返回 **HTTP 402**。详见 [计费说明](./计费说明)。
