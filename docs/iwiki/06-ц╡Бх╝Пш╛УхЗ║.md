# 流式输出

将请求体中的 `stream` 设为 `true`，响应为 **Server-Sent Events（SSE）**，以增量方式返回模型输出。

## 平台行为

为准确计费，当 `stream=true` 时，平台会在转发上游前确保：

```json
"stream_options": { "include_usage": true }
```

你可自行传入其它 `stream_options` 字段，平台会合并并强制 `include_usage`。

## 请求示例

```bash
curl https://api.ssemarket.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${SSEAPI_KEY}" \
  -N \
  -d '{
    "model": "qwen3.8-27b-awq",
    "messages": [{"role": "user", "content": "写一首七言绝句"}],
    "stream": true,
    "max_tokens": 256,
    "chat_template_kwargs": {"enable_thinking": false}
  }'
```

## SSE 形态（示意）

```text
data: {"id":"...","choices":[{"delta":{"content":"床"},"index":0}]}

data: {"id":"...","choices":[{"delta":{"content":"前"},"index":0}]}

data: {"id":"...","choices":[{"delta":{},"finish_reason":"stop"}],"usage":{"prompt_tokens":20,"completion_tokens":40,"total_tokens":60,"prompt_tokens_details":{"cached_tokens":0}}}

data: [DONE]
```

- 中间 chunk：`choices[].delta.content` 为增量文本
- 末包：带 `finish_reason`，并尽量带完整 `usage`
- 流以 `data: [DONE]` 结束

## Python（OpenAI SDK）

```python
from openai import OpenAI

client = OpenAI(api_key="sk-...", base_url="https://api.ssemarket.cn/v1")

stream = client.chat.completions.create(
    model="qwen3.8-27b-awq",
    messages=[{"role": "user", "content": "写一首七言绝句"}],
    stream=True,
    stream_options={"include_usage": True},
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)

for chunk in stream:
    delta = chunk.choices[0].delta.content if chunk.choices else None
    if delta:
        print(delta, end="", flush=True)
    if getattr(chunk, "usage", None):
        print("\nusage:", chunk.usage)
```

## 计费时机

流式响应在连接结束后由平台根据缓冲的 SSE 解析 usage 并扣费。客户端中途断开仍可能已产生上游费用（取决于上游实现）；请合理设置 `max_tokens`。
