# 多模态（图像理解）

当管理员在管理台为模型开启 **多模态** 后，你可以在 `messages[].content` 中传入图片（OpenAI 兼容的 `image_url`）。

## 前置条件

1. 控制台模型卡片显示「多模态」标签
2. 未开启却传图 → HTTP 400，`multimodal_not_enabled`

## content 数组格式

```json
{
  "role": "user",
  "content": [
    {
      "type": "image_url",
      "image_url": {
        "url": "https://example.com/a.png"
      }
    },
    {
      "type": "text",
      "text": "描述这张图"
    }
  ]
}
```

`image_url.url` 支持：

- 公网 / 上游可达的 HTTP(S) URL
- Data URL：`data:image/png;base64,<BASE64>`（或 jpeg/webp 等）

## curl 示例（Base64）

```bash
KEY="sk-你的密钥"
B64=$(base64 -w0 your.png)   # macOS 可用 base64 -i your.png | tr -d '\n'

curl https://api.ssemarket.cn/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"qwen3.8-27b-awq\",
    \"messages\": [{
      \"role\": \"user\",
      \"content\": [
        {\"type\": \"image_url\", \"image_url\": {\"url\": \"data:image/png;base64,$B64\"}},
        {\"type\": \"text\", \"text\": \"描述这张图\"}
      ]
    }],
    \"max_tokens\": 128,
    \"chat_template_kwargs\": {\"enable_thinking\": false}
  }"
```

> 注意：从平台 Pod 访问上游时，图片 URL 必须对**上游推理机**可达；`127.0.0.1` 指向容器自身。大图 Base64 会显著增大请求体。

## 计费

平台会统计请求中的图片张数，写入用量日志「图片」列。

管理员可配置：

| 模式 | 行为 |
| --- | --- |
| 按 token | 图片计入上游 prompt；可另配图片 token 单价 |
| 按张 | `张数 × ¥/张`，并从 prompt 扣除「每图预估 tokens」防双重计费 |

详见 [计费说明](./计费说明)。

## 多图

同一条 user message 的 `content` 数组中可放多张 `image_url`（以上游与模型能力为准；控制台描述中可能写明上限，例如最多 4 张）。
