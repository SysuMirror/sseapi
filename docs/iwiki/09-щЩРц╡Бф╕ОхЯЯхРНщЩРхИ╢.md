# 限流与域名限制

## 限流（RPM / 并发）

平台在 `/v1` 代理层做强校验：

| 维度 | 说明 |
| --- | --- |
| RPM | 每分钟请求数 |
| 最大并发 | 同时进行中的请求数（流式请求占用至结束） |

优先级（从高到低覆盖）：**模型配置 → API Key → 用户 → 平台默认**。某层填 `0` 表示继承上一层。

超限返回 **HTTP 429**。

管理员可在管理台 **限流** Tab 配置全局默认，并在用户 / 模型上覆盖。

## 域名限制（浏览器）

可为「模型」或「API Key」配置允许域名（Origin / Referer）：

- 支持完整 Origin，如 `https://app.example.com`
- 支持通配，如 `*.ssemarket.cn`
- **留空 = 不限制**
- **无 Origin 的服务端调用始终放行**

未命中返回 **403**，`type=origin_forbidden`。

### 配置入口

- 管理台 → 模型 → 允许域名  
- 控制台 → API 密钥 → 编辑密钥的允许域名  

## 建议

| 场景 | 建议 |
| --- | --- |
| 后端服务调用 | 不配域名限制即可 |
| 前端直连 API | 为模型或 Key 配置前端 Origin，并注意 CORS / 密钥泄露风险；生产更推荐后端代发 |
| 高频任务 | 适当提高并发 / RPM，或做客户端排队 |
