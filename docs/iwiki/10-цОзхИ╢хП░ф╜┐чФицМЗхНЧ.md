# 控制台使用指南

控制台地址：https://platform.ssemarket.cn

使用学院 SSE Market OAuth 登录。

## 功能导航

| 菜单 | 作用 |
| --- | --- |
| 概览 | 余额、近期用量摘要、快捷入口 |
| API 密钥 | 创建 / 吊销密钥；查看 API 根地址 |
| 用量 | 按日 / 按模型 / 最近调用（含缓存、图片张数） |
| 余额与流水 | 充值与扣费流水 |
| 模型 | 模型卡片、单价、展开描述、跳转 API 文档 |
| 文档 | 跳转本 iWiki 空间（管理员可改链接） |
| 管理台 | 仅管理员：模型注册、定价、多模态、限流、用户额度、文档外链 |

## 推荐流程

1. 登录控制台  
2. **API 密钥** → 创建并保存明文  
3. **模型** → 确认 Slug 与单价、是否多模态  
4. 按 [首次调用 API](./首次调用API) 发请求  
5. 在 **用量** / **余额与流水** 核对扣费  

## 管理员：注册模型

管理台 → **模型** → **注册模型**：

- 上游 Base URL：OpenAI 兼容根，需含 `/v1`（集群可达地址，勿填容器无法访问的 `127.0.0.1`）  
- 上游模型名：vLLM `--served-model-name`  
- Slug：用户调用的 `model`  
- 输入 / 缓存 / 输出价（¥/1M，缓存可到 `0.001`）  
- 可选：多模态、图片按 token 或按张  
- 保存后可用 **非流式 / 流式测试** 探测连通性（不计费）  

## 管理员：文档外链

管理台 → **文档**：配置侧栏「文档」跳转的 iWiki URL（默认本空间）。
