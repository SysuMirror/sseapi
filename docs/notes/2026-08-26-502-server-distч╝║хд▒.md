# platform 502：server/dist/index.js 缺失

## 现象

部署日志显示 SUCCESS / 网关已写 `23009`，但 `platform.ssemarket.cn` / `api.ssemarket.cn` 仍 **502**。

Pod stderr：

```text
Error: Cannot find module '.../server/dist/index.js'
```

frp `127.0.0.1:23009` → Empty reply（应用未监听 8080）。

## 根因

1. `deploy.sh` 跑完 web build 后 `exec node dist/index.js`，但 **server 未产出 dist**（或未带进包）。
2. supervisord `startsecs` 很短 → 部署平台过早判 RUNNING 并写网关（`waitForFrpHealth` 需更新 sdpy-api 才生效）。

## 修复

1. **pack-sseinfra.ps1**：打包前本地 `tsc` + `vite build`，zip **必须含** `server/dist/index.js` 与 `web/dist/index.html`；排除 `.npm-cache`。
2. **deploy.sh**：`dist` 已存在则跳过构建、只 `npm ci --omit=dev`；启动前断言 dist 存在；构建前 `unset NODE_ENV`。
3. 流式计费：代理侧已强制 `stream_options.include_usage=true`，并解析末包 `usage.prompt_tokens_details.cached_tokens`。

## 你要做的

上传新的 `基础服务/api-platform/sseapi-sseinfra.zip`（约 0.3MB，含预编译 dist）→ ai-platform **重新部署正式**。

日志应出现：

```text
[deploy] server/dist 已存在，跳过 tsc
[deploy] web/dist 已存在，跳过 vite build
[deploy] starting node dist/index.js
```

然后 `curl https://api.ssemarket.cn/api/health` → 200。
