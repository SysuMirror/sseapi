# API 根地址显示修复

## 背景

管理台「API Keys」页「API 根地址」误显示为 `https://platform.ssemarket.cn`（控制台域名），用户调用 OpenAI 兼容接口应使用 `https://api.ssemarket.cn`。

## 根因

- `deploy.sh` 将 `PUBLIC_BASE` 默认设为控制台域 `platform.ssemarket.cn`（用于 OAuth 回调等）。
- `keys.ts` 的 `/config` 优先读 `PUBLIC_BASE` 作为 `apiHost`，与 API 域混用。

## 改动

1. `server/src/config.ts`：新增 `resolveApiPublicBase()` / `apiPublicBase`，优先 `SSEAPI_API_PUBLIC_URL`、`SDPY_API_PUBLIC_URL`；若 `PUBLIC_BASE` 为 `platform.*` 则自动映射为 `api.*`。
2. `keys.ts`、`docs.ts` 改用 `config.apiPublicBase`。
3. `deploy.sh` 显式 export `SSEAPI_API_PUBLIC_URL=https://api.ssemarket.cn`。
4. 密钥页增加 base_url 提示（路径含 `/v1`）。

## 验证

1. 重新部署 ai-platform 后登录管理台 → API Keys →「API 根地址」应为 `https://api.ssemarket.cn`。
2. `curl https://api.ssemarket.cn/api/health` 正常。
3. 创建新密钥，curl 示例中的 host 为 `api.ssemarket.cn`。

## 未决

- 线上需 redeploy 后生效；已吊销密钥与本次修复无关。
