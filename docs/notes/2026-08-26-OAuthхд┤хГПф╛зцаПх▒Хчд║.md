# OAuth 头像侧栏展示

## 背景

侧栏用户区原先只用姓名首字母占位，未展示 OAuth IdP 回传的头像。

## 结论

- `fetchOAuthUserInfo` 兼容字段：`avatar_url` / `avatarUrl` / `AvatarURL` / `avatar` / `picture`，统一写入 `users.avatar_url`
- `/api/auth/me`、登录 userinfo 已通过 `publicUser.avatarUrl` 下发
- `AppShell`：有 `avatarUrl` 则显示圆形图片，加载失败回退首字母

## 关键路径

- `server/src/services/oauth.ts`
- `web/src/components/AppShell.vue`

## 验证

重新登录（或刷新后 `/me` 带上 avatarUrl）→ 侧栏底部应显示头像。若本地已登录但无头像，需重新走一遍 OAuth 以写入库。

## 部署

含 server + web，需 rebuild 部署 `sseapi-sseinfra.zip`。
