# SSE API Platform：对象存储（桶为主、本机为备份）

> 日期：2026-08-26

## 背景

用户要求：**业务数据以 MinIO 桶为主存储**，Pod/PVC 上的 `DATA_DIR` 仅作**本地备份**（与图床「二进制进桶」一致，但 sseapi 的主数据是单文件 JSON）。

## 存储约定

| 层级 | 路径 | 角色 |
|------|------|------|
| **MinIO 桶（主）** | `data/sseapi-store.json` | 用户、密钥、模型、用量、流水、文档等全部状态 |
| **PVC / DATA_DIR（备）** | `{DATA_DIR}/sseapi-store.json` | 每次写入后同步一份；启动时若桶空而本地有则**自动上传到桶** |

判断逻辑（`server/src/storage.ts`）：

- 四个 `MINIO_*` 齐全 → 读桶、写桶，并写本地备份
- 否则（本地开发）→ 仅读写 `DATA_DIR`

启动日志示例：

```text
[sseapi] store=minio:sdpy-sseapi-p local_backup=/home/cloud/data/sseapi-store.json
```

## 在 SSE Deploy 申请桶（你要做的）

完整手册：`sse-deploy/docs/iwiki-SSE-Deploy-对象存储用户手册.md`

### 1. 进入对象存储页

1. 打开 https://ssemarket.cn/sdpy/ 登录  
2. 进入 **项目 → sseapi 模块**  
3. 点 **「对象存储（MinIO）」** 或环境栏 **「对象存储」**  
4. 地址：`/sdpy/modules/{模块ID}/object-storage?env=prod`（测试环境切 `env=test`）

### 2. 开通桶

任选其一：

| 方式 | 操作 |
|------|------|
| **申请对象存储** | 提交审批；平台管理员通过后自动建桶 + 发密钥（标签=组名） |
| **确保桶存在** | 有权限时幂等建桶+发密钥（不删已有桶） |

桶名通常与 K8s **组名**相同，如 `sdpy-sseapi-p`（正式）、`sdpy-sseapi-t`（测试）。

### 3. 部署以注入 MINIO_*

回模块页 **部署测试/正式**，组须 **Running**。部署成功后 Pod 环境会有：

| 变量 | 典型值 |
|------|--------|
| `MINIO_ENDPOINT` | `http://minio.platform-infra.svc.cluster.local:9000` |
| `MINIO_ACCESS_KEY` | 面板发的 key |
| `MINIO_SECRET` | 面板发的 Secret |
| `MINIO_BUCKET` | 与组名相同 |

**密钥 label 必须等于组名**，否则 deploy 不会注入。

### 4. 历史数据（可选）

若 Pod 里已有 `sseapi-store.json`、桶里还没有：

- 对象存储页点 **「同步历史数据到桶」**（平台会把 `MODULE_DATA` 下文件推到桶）  
- 或 **直接重部署**：应用启动时会检测「桶空 + 本地有文件」并自动上传

> 平台同步主要面向图床等二进制；sseapi 的日常读写由应用直连桶，不依赖同步任务。

### 5. 验证

1. 部署日志：`[deploy] store=minio:sdpy-sseapi-p`  
2. 应用日志：`[sseapi] store=minio:sdpy-sseapi-p`  
3. 控制台改一条数据（如创建 API Key）后，教师面板 http://ssemarket.cn:24000/storage 查看桶内 `data/sseapi-store.json` 时间戳更新  

## 与图床差异

| | 图床 | sseapi |
|---|------|--------|
| 桶内容 | 图片二进制 | 单 JSON 状态文件 |
| 元数据 | SQLite 仍在 PVC | 无 SQLite，JSON 即全部状态 |
| 主备策略 | MinIO 优先，PVC 元数据 | **桶为主，PVC 为备份** |

## 代码路径

- `server/src/storage.ts` — MinIO / 本地读写
- `server/src/db.ts` — `initDb()` 启动加载、`persist()` 异步落盘
