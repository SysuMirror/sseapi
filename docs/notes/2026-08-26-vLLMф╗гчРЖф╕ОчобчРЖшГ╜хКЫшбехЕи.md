# API Platform：vLLM 代理计费与管理能力补全

> 日期：2026-08-26

## 背景

控制台 `platform.ssemarket.cn` + API `api.ssemarket.cn`。底层模型以 vLLM（OpenAI 兼容）为主，需在平台注册上游、限制域名、转发并记用量，管理端定价与手动额度。

## 本次补全

1. **模型**：`upstream_api_key`、`allowed_origins`；管理台可配 vLLM Base URL / served-model-name / 密钥 / 定价 / 域名
2. **代理**：按模型密钥转发；模型+密钥双重域名校验；`GET /v1/models`；`/v1` CORS 反射 + 业务层 403
3. **个人 API Key**：创建/吊销/域名限制；`GET /api/keys/config` 返回 API 根地址；前端创建弹层 + curl 示例
4. **计费**：调用按 token 扣费；`GET /api/billing/summary` 累计充值/消费；流水页分页
5. **用户额度**：增减余额 + **设定余额绝对值**；用户详情接口（近期用量/流水）
6. **统计**：近 30 日按模型汇总
7. 文档与 README 对齐双域与 vLLM 注册流程

## 验证

```powershell
cd 基础服务/api-platform/server; npm run build
cd ../web; npm run build
```
