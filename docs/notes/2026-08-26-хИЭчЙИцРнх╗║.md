# SSE API Platform 初版搭建

> 日期：2026-08-26  
> 路径：`基础服务/api-platform/`  
> 建议模块名：`sseapi`

## 背景

新建「API 开放平台」：发布模型 API、密钥、用量/计费、文档；管理员配置上游地址、展示卡片与价格。风格参考 DeepSeek Platform / Cursor Usage。Logo 后续替换。

## 已交付

### 用户侧（普通用户侧栏无「管理台」入口）

- 登录：SSE Market OAuth（左右分栏深色品牌 + 白底登录）
- 概览 / API Keys / 用量 / 余额流水 / 模型卡片 / 文档
- `POST /v1/chat/completions`（Bearer `sk-…`，按 token 计费）

### 管理台（`user.isAdmin` 才可见）

- 模型：slug、展示名、徽章、卡片色、上游 Base URL、上下游模型名、输入/输出 ¥/1M、启停
- 用户：搜索、充值/扣款、设管理员
- 文档：Markdown 编辑
- 总览统计

管理员种子：`PLATFORM_ADMIN_OAUTH_IDS`（Market `user_id` 逗号分隔）；登录时自动抬权。

### 技术

| 项 | 说明 |
|----|------|
| 前端 | Vue 3 + TS + Vite，IBM Plex Sans |
| 后端 | Express，单端口托管 SPA + API |
| 存储 | `DATA_DIR/sseapi-store.json`（无原生依赖，便于 K8s） |
| 部署 | 仓根 `deploy.sh`，听 `0.0.0.0:$PORT` |

## 部署注意

1. 在集市注册 OAuth 应用，回调示例：`https://ssemarket.cn/sdpy/sseapi/oauth/callback`
2. 模块环境变量配置：`SSEAPI_OAUTH_*`、`PLATFORM_ADMIN_OAUTH_IDS`、`JWT_SECRET`；可选 `SSEAPI_UPSTREAM_API_KEY`
3. sdpy 创建模块 `sseapi` → 上传 zip（含 `deploy.sh`）或挂 Git → 部署
4. 访问：`https://ssemarket.cn/sdpy/sseapi/`（测试：`/sdpy/test/sseapi/`）

## 本地验证

```powershell
cd 基础服务/api-platform/server
copy .env.example .env   # 填 OAuth
npm install && npm run dev

cd ../web
npm install && npm run dev
```

`npm run build`（server + web）已通过。
