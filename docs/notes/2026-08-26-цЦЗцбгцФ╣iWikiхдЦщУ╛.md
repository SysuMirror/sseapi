# 文档改为 iWiki 外链

## 背景

平台内 Markdown 文档不再维护，统一跳转学院 iWiki；管理员可配置链接。

## 结论

- 默认：`https://ssemarket.cn/iwiki/space/space-R0M8mXw2`
- 存储：`docs.external_url`（迁移时自动写入默认值）
- 侧栏「文档」外链新开页；概览/密钥快捷入口同理
- 管理台「文档」Tab：配置标题 + 跳转 URL（不再编辑 Markdown）
- `/docs` 路由仅作跳转中转页

## 关键路径

- `server/src/db.ts`、`routes/docs.ts`、`routes/admin.ts`
- `web/src/store/docs.ts`、`AppShell.vue`、`AdminView.vue`、`DocsView.vue`、`OverviewView.vue`、`KeysView.vue`

## 部署

rebuild `sseapi-sseinfra.zip`。已有环境首次启动会 migrate 补上默认 URL。
