# 管理台模型连通性测试

## 背景

注册/编辑模型后，管理员需要在管理台当场验证上游 vLLM（OpenAI 兼容）是否可达，覆盖非流式与流式 `chat/completions`，且不计费；并希望看到用户侧模型卡片预览。

## 结论

- 后端：
  - `POST /api/admin/models/test`：草稿探测（未保存也可测，body 必填上游字段）
  - `POST /api/admin/models/:id/test`：已保存模型；body 可覆盖上游字段
  - 直连 `{base}/chat/completions`；流式强制 `include_usage`；超时 120s；不计费
- 前端（注册/编辑表单内）：
  - 顶部：**用户「模型」页卡片实时预览**
  - 底部区块：**测试 API 可用性**（非流式 / 流式按钮）
  - 列表行仍有「测试」快捷入口

## 关键路径

- `server/src/routes/admin.ts`
- `web/src/api/index.ts`
- `web/src/views/AdminView.vue`

## 验证

1. 重新部署 ai-platform 后硬刷新管理台（旧包只有「保存/取消」）
2. 点「注册模型」→ 填 Base URL + 上游模型名 → 「非流式测试」/「流式测试」
3. 改展示名称/价格时，上方预览卡应同步变化

## 部署

需 rebuild 部署 `sseapi-sseinfra.zip`。

## 注意

平台 Pod 内访问上游时，`127.0.0.1` 指向容器自身，不是你本机 vLLM；应填集群可达地址。
