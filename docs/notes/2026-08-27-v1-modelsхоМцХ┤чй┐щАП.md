# GET /v1/models 与控制台同构穿透

> 日期：2026-08-27

## 背景

用户调用 `GET https://api.ssemarket.cn/v1/models` 仅返回 OpenAI 最小字段（id/object/created/owned_by），缺少多模态、思考档位、定价等控制台已有信息。

## 结论

- 新增 `server/src/services/model-catalog.ts` 统一映射
- `GET /v1/models` 与 `GET /api/models` **同构**：spread 控制台字段 + OpenAI 必需字段（`id`=slug、`object`、`created`、`owned_by`）
- 模型表扩展：`thinking_enabled`、`thinking_levels`、`default_thinking`（migrate 默认值）
- 管理台模型表单可配置思考/推理档位

## 验证

```powershell
$headers = @{ Authorization = "Bearer sk-..." }
Invoke-RestMethod -Uri "https://api.ssemarket.cn/v1/models" -Headers $headers | ConvertTo-Json -Depth 10
```

应含 `multimodalEnabled`、`thinking`、`pricing`、`capabilities` 等。

## 部署

重建 ai-platform / sseapi 模块（api dist + web dist），浏览器 Ctrl+F5。

## 管理台

对 `qwen3.8-27b-awq` 等模型勾选「思考/推理」、多模态，保存后 `/v1/models` 即反映。
