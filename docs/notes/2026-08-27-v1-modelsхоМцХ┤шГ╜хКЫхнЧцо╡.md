# GET /v1/models 返回完整模型能力

> 日期：2026-08-27

## 背景

用户调用 `GET /v1/models` 仅得到 OpenAI 最小字段（id/object/created/owned_by），缺少思考强度、推理档位、多模态/图片支持、定价等。

## 改动

- 新增 `server/src/services/model-catalog.ts`：`mapModelV1` / `mapModelConsole`
- `GET /v1/models` 扩展返回：
  - `name`、`description`、`badge`
  - `capabilities`（vision / thinking / reasoning）
  - `pricing`（CNY 单价）
  - `thinking`（supported、levels、default、request_key）
  - `multimodal`（enabled、billing_mode、图片价）
  - `limits`（rpm、并发、域名限制）
- 模型表新增：`thinking_enabled`、`thinking_levels`、`default_thinking`（migrate 自动补默认）
- 管理台模型表单可配置思考档位

## 验证

```powershell
Invoke-RestMethod -Uri "https://api.ssemarket.cn/v1/models" -Headers @{ Authorization = "Bearer sk-..." }
```

部署后需在管理台为 Qwen 等模型勾选「思考/推理」、开启多模态，否则对应字段为 false。

## 部署

重建 ai-platform / sseapi 模块（与此前 api-platform zip 流程相同），`Ctrl+F5` 强刷无关（纯 API）。
