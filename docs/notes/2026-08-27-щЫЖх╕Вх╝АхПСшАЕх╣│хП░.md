# 集市开发者平台

## 背景

平台定位调整为「集市开发者平台」：开发者中心仅对**标记用户**可见；管理员可维护入口与模块注册表。

## 能力

### 可见性

- `UserRow.is_developer`：标记开发者
- 管理员自动拥有开发者权限
- 侧栏「开发者」区：`isDeveloper || isAdmin` 可见

### 开发者中心（`/developer`）

- 按分类展示平台入口（seed 含数据库管理、模块注册、API 开放平台）
- 数据库管理外链：`https://db.ssemarket.cn/`

### 模块注册（`/developer/modules`）

- 开发者可提交注册（草稿）
- 查询：`GET /api/dev-modules`、`GET /api/dev-modules/:slug`
- 扩展字段：`extra` JSON 对象

### 管理台新增 Tab

- **开发者**：分页列表、按 userId/oauthId 添加、取消标记
- **平台入口**：CRUD 开发者中心卡片
- **模块注册**：CRUD、审核发布（status: draft/active/disabled）

## API 摘要

| 路径 | 说明 |
|------|------|
| `GET /api/developer/hub` | 开发者中心聚合（需开发者） |
| `GET /api/dev-modules` | 模块列表（分页） |
| `GET /api/dev-modules/:slug` | 模块详情 |
| `POST /api/dev-modules` | 开发者提交注册 |
| `GET /api/developers` | 开发者名单（分页，需 JWT） |
| `GET /api/developers/check?oauthId=` | 判断是否开发者（oauthId 可不带 JWT） |
| `GET /api/developers/check` | 当前用户（需 JWT） |
| `GET /api/developers/me` | 当前用户开发者状态详情 |
| `POST /api/developers/check-batch` | 批量检查 oauthId（需 JWT，最多 50） |
| `GET /api/admin/developers` | 管理员：开发者列表 |
| `POST /api/admin/developers` | 管理员：添加标记 |
| `GET/POST/PUT/DELETE /api/admin/platform-entries` | 平台入口 |
| `GET/POST/PUT/DELETE /api/admin/dev-modules` | 模块管理 |

## 验证

1. 管理台 → 开发者 → 添加 oauthId → 该用户登录后见侧栏「开发者中心」
2. 开发者中心可见「数据库管理」入口
3. 模块注册页提交 → 管理台审核为 active → 列表可查
