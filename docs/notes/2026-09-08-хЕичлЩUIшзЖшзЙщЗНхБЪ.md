# 全站 UI 视觉重做（设计令牌 + 组件基元）

日期：2026-09-08
范围：`web/src`（样式系统 + 全部 8 个页面 + 外壳）

## 背景

用户反馈「当前的全部页面都有点丑，生成级别不够专业」。原有样式虽已有 CSS 变量，
但存在以下问题：

- 令牌不成体系：颜色只有十几个散装变量，缺少中性色阶、阴影分级、间距/字号刻度；
- 阴影过淡（单一 `0 1px 2px`），卡片几乎「贴」在背景上，缺少层次；
- 圆角/内边距/字号在各页面各写各的（12/13/14/18/20px 混用）；
- 交互态缺失：hover/focus/disabled 覆盖不全，表格行无 hover，无空状态图标；
- 硬编码颜色散落在各页（`#f2f3f5`、`#ecfdf5`、`#64748b` 等），与语义色脱节。

判定为**设计系统增强模式**（已有变量 + 统一语言 + 品牌色），不推翻重来，
而是补齐令牌、统一基元、提升执行精度。

## 结论

保留品牌蓝 `#3370ff` 与 IBM Plex 字体栈，重写 `styles/main.css` 建立完整令牌体系，
各页面只做「消费令牌」的精修，不新增设计语言。

## 关键改动

### 1. `web/src/styles/main.css`（重写）

- **中性色阶** `--n-0 … --n-900`：带极轻冷调，替代原来的散装灰。
- **语义色**：每个状态都有 `-soft` / `-ink` 三件套（ok/warn/danger/info/violet），
  页面不再直接写 `#ecfdf5` 这类值。
- **阴影分级** `--shadow-xs/sm/md/lg`：多层叠加（1px 描边 + 大模糊），卡片有了真实层次。
- **间距** `--sp-1 … --sp-10`、**字号** `--fs-xs … --fs-3xl`、**圆角** `--radius-xs … --radius-xl`。
- **动效**：统一 `--ease` / `--dur`，加 `fade-up` 入场动画，并遵守 `prefers-reduced-motion`。
- **组件基元**：`btn`（primary/ghost/danger/sm）、`card`、`panel`、`field`、
  `table`（行 hover、表头浅底、圆角裁切）、`badge`、`stat`、`empty`、`pager`、
  `row-between`、`table-scroll`。
- `select` 统一自绘箭头（`appearance: none` + 内联 SVG），跨浏览器一致。
- 自定义细滚动条。

### 2. 外壳 `components/AppShell.vue`

- 侧栏宽度 `232px → 244px`（`--sidebar-w`），导航激活态加左侧 3px 品牌竖条；
- 导航项 hover 时图标由 0.7 提到 1；管理分组标题改为大写字距；
- 品牌名/用户名用 `--ink-strong`，余额用等宽数字（`tabular-nums`）；
- 窄屏侧栏折叠为横向换行导航。

### 3. 各页面

| 页面 | 要点 |
|------|------|
| `OverviewView` | 4 张统计卡各带不同色左侧竖条（品牌/紫/绿/橙）区分语义；快捷操作改 2×2 网格；趋势图 hover 提亮 |
| `KeysView` | 根地址卡层次重做；密钥揭示区用 `brand-softer` 底 + 蓝色描边；弹窗加遮罩模糊 + 缩放入场；表格行 hover |
| `UsageView` | 5 张统计卡；近 3 天柱状图加宽（`max-width: 64px`）；表头筛选行浅底 + 大写小标签 |
| `BillingView` | 统计卡与面板统一间距；正负金额用语义色 + 字重 |
| `ModelsView` | 卡片 hover 上浮 1px + 阴影加深；价格表表头大写小标签；标签色全部换语义令牌 |
| `LoginView` | 背景渐变改品牌蓝 + 紫色第二光源；logo 加投影；CTA 阴影加强 |
| `OAuthCallbackView` | 加旋转 loading 指示器（原来只有一行文字） |
