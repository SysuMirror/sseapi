# 模型「仅开发者可见/可调用」（dev_only）

## 背景
部分模型（如内部调试/高价/敏感模型）只在集市开发者之间使用，不应暴露给普通用户。需要一个开关，让管理员在注册/编辑模型时勾选「仅对集市开发者可见」，该模型对普通用户不可见、不可调用。

## 结论
1. `ModelRow` 新增 `dev_only`（0/1）。开启后：
   - **列表**：控制台 `/api/models`、公开 `/v1/models`、`/v1/models/:id` 对非开发者隐藏（呈现为「不存在」）。
   - **调用**：chat/messages/responses/embeddings/rerank/images 入口对非开发者返回 `403 dev_only_forbidden`。
   - **管理员**恒可见/可调用（管理台不受影响）。
2. 开发者身份复用「集市开发者平台」开放 API（`checkDeveloper`），带 **2 分钟内存缓存**避免列表/调用频繁打接口。平台未配置或查询失败 → 按非开发者处理（fail-closed）。管理员内置判定（`is_admin` 直接放行）。

## 关键路径
- 类型/迁移：`server/src/db.ts` → `ModelRow.dev_only`，seed 默认 `0`，migrate 兜底 `if (m.dev_only == null) m.dev_only = 0`。
- 探测行补齐：`server/src/routes/admin.ts` `probeModelRow()`、`server/src/services/protocol-support.ts` `buildProbeRow()`。
- 身份判定：`server/src/services/dev-platform.ts` → `userIsDeveloper(oauthId)`（缓存）+ `mayAccessDevOnly(req)`（admin 恒可，否则查开发者）。
- 列表过滤：`server/src/routes/models.ts`（console）、`server/src/routes/proxy.ts` `/models` 与 `/models/:modelId`。
- 调用拒绝：`server/src/routes/proxy.ts` 的 `chat/completions`、`messages`、`responses` 三个入口内联检查；`server/src/services/proxy-common.ts` `resolveModelForProxy`（embeddings/rerank/images 共用）内联检查。
- 暴露：`mapModelAdmin`/`mapModelConsole` 输出 `devOnly`。
- 前端：`web/src/views/AdminView.vue` → 模型表单「仅对集市开发者可见」开关、默认 `devOnly:false`、保存体 `devOnly`、列表卡片徽标 `.pill-dev`。
- 部署压缩包：`sseapi-sseinfra.zip`（含 server/dist、web/dist）。

## 验证
- `cd server && npm run build`、`cd web && npm run build` 通过。
- E2E `server/.e2e-test/dev-only.mjs`：
  - 管理员 `/api/models` 见 `dev-secret`。
  - 开发者 `/api/models` 见 `dev-secret`。
  - 普通用户 `/api/models` 不见 `dev-secret`（但见 `public-model`）。
  - 开发者调用 `dev-secret` → 200；普通用户调用 → `403 dev_only_forbidden`。
  - `/v1/models`：开发者见 `dev-secret`，普通用户不见。
- 回归：`dev-platform.mjs`、`context-length.mjs`、`tool-cycle.mjs` 均通过。

## 未决事项
- 开发者判定依赖外部开发者平台可用性；平台不可用时 dev_only 模型会 fail-closed（隐藏/拒绝所有人），属预期安全行为，但需确保开发者平台在线，否则开发者也无法使用。
- 开发者缓存 TTL=2 分钟：开发者身份变更（新授权/取消）后最多 2 分钟生效。
