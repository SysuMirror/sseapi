# 用户 Token 面板 / 用量界面重做 / 并发面板重设计

日期：2026-09-08

## 背景

用户提出三块需求：

1. 给每个人做一个 Token 面板，记录每次 API 调用的日志（含提示词），管理员界面支持按用户区分、表格样式查看全体。
2. `https://platform.ssemarket.cn/usage` 用量界面优化：柱状图只显示近 3 天；把上面的筛选去掉，移到表格（Excel 风格表头筛选）；只保留一个表格；把个人 Token 面板做进去。
3. `api 并发` 页面重新设计：好看一点、不要抽象，支持实时查看哪些用户/模型在用。

## 改动

### 后端

- **`server/src/db.ts`**
  - `UsageRow` 新增 `prompt: string` 字段（提示词预览）。
  - `migrate()` 对旧 `usage_logs` 补 `prompt = ''`。

- **`server/src/services/proxy-common.ts`**
  - 新增 `promptPreview(req)`：从 `req.body` 提取提示词（兼容 chat/messages 的 `messages`、embedding 的 `input`、rerank 的 `query`+`documents`、以及 `prompt/question/instruction/text/content` 兜底），脱敏 `data:image` base64，统一截断到 `PROMPT_PREVIEW_MAX`(2000)。
  - `appendUsage()` 新增末位可选参数 `prompt`，写入 `usage_logs.prompt`（缺省自动调 `promptPreview`）。
  - `settleBilling()` 新增末位可选参数 `prompt`，透传给 `appendUsage`。末位可选参数不影响既有调用点。

- **`server/src/routes/usage.ts`**
  - `/logs`：管理员可透传 `userId` 下钻指定用户；items 增加 `model_type`。
  - 新增 `GET /api/usage/by-user`（仅管理员）：按用户聚合请求/Tokens/Prompt/Completion/缓存/费用/错误；支持 `days/model/status/type` 筛选；`userId` 下钻返回 `detail` 分页明细（含 `prompt`）。

- **`server/src/services/rate-limits.ts`**
  - `getRuntimeStatus()`：`users`/`activeUsers` 条目附加用户 `name`；新增 `activeUsers`（仅 `current>0`）。

### 前端

- **`web/src/api/index.ts`**
  - 新增 `usageByUser(q)` → `GET /api/usage/by-user`。

- **`web/src/views/AdminView.vue`**
  - 新增标签页 `用户用量`，接入 `api.usageByUser`：按用户表格 + 点击「查看」下钻明细（含提示词、状态，支持模型/状态筛选与分页）。
  - 重设计「实时并发」面板：顶部「全局处理中」大数字 + 限流开关 tag + 三个统计卡（正在使用的用户/活跃模型/活跃端点）；「正在使用的用户」chips（高亮 + 并发数）；「活跃模型」进度条；底部端点表+用户表。
  - 计算属性 `activeUsers/activeModels/activeEndpoints` + 函数 `modelPct`。

- **`web/src/views/UsageView.vue`（整页重做）**
  - 顶部 5 张汇总卡片（请求/Tokens/缓存/消费/错误）。
  - 「近 3 天 Tokens」柱状图（固定 3 天，不受筛选影响）。
  - 唯一「调用明细」表格：表头第一行为筛选行（时间/模型/类型/状态），第二行为列名；新增「提示词」列与「类型」列；分页。
  - 移除原先分散的「按日/按小时/按请求/按模型」多表格。

## 验证

- 新增 e2e `server/.e2e-test/usage-prompt-users.mjs`：验证 ① chat 时 `usage_logs` 记录 `prompt` 与 `model_type`；② `/api/usage/by-user` 按用户聚合 + `userId` 下钻明细；③ 非管理员访问 `by-user` 返回 403。全部通过。
- 全量 e2e 回归（run-protocol / tool-cycle / stream-marker / usage-aggregate / rate-limit / chat-reasoning / rerank / probe-usage / usage-prompt-users）全部通过。
- 新增 `dev-app.mjs`（生产构建 + mock 上游 + 种子数据），供人工浏览器验证（本次浏览器 MCP 不可用，故以静态代码 + 后端接口验证替代）。

## 未决 / 注意

- 浏览器 MCP（`cursor-ide-browser`）当前不可用，未能截图确认 UI 渲染；代码已通过类型检查与构建，后端接口由 e2e 验证。
- `prompt` 仅存文本预览（≤2000 字符），不存图片 base64，避免日志膨胀。
- `/logs` 无 `userId` 时管理员只看自己的日志；要看全体请用 `/by-user` 或透传 `userId`。
