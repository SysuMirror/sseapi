# 管理台用户用量对接「集市开发者」身份与需求单

日期：2026-09-08

## 背景

用户提供多篇 iWiki 文档（开发者平台使用指南/开放 API 等），要求：`api-platform`（SSE Market / API 网关）在管理台显示用户 usage 时，能判断登录用户是**集市开发者**还是**普通用户**，若是开发者则展示其**需求单**，方便管理，且要美观。

调研结论：集市开发者平台已被拆分为独立服务 `developer-api`（developer.ssemarket.cn），其开放 API 提供：
- `GET /api/open/developers/check?oauthId=` → 判断某集市 oauthId 是否开发者（返回 `isDeveloper`/`isAdmin`/`userId` 平台内部id/`displayName`）。
- `GET /api/open/users/:userId/reqs` → 按负责人查询该用户「在做哪些需求」（标题/阶段/优先级/期望完成时间/所属业务）。

两端数据分离，`api-platform` 需跨服务调用，鉴权为 SM2 模块签名。项目管理台 oauth_id 与开发者平台 oauth_id 同源（集市 user_id），可匹配。

## 结论 / 改动

### 对接方式（用户确认）

- 走**开放 API（SM2 模块签名）**，模块名 `platform`，私钥见 `deploy/oauth.env`。
- 展示粒度：按用户聚合行**标注角色徽标**（管理员/开发者/普通用户），下钻时展示**需求单列表**。

### 后端

1. 新增 `server/src/services/dev-platform.ts`：
   - `buildModuleAuthToken`：按开发者平台契约生成 token（`base64url(slug).base64url(ts).base64url(nonce).base64url(sm2sign)`，签名串 `slug\nts\nnonce\nqueryTime`，SM2 `hash:true, der:false`）。
   - `checkDeveloper(oauthId)` / `userReqs(userId)` / `developerOverview(oauthId)`。
   - `isDevPlatformConfigured()`：未配置私钥时跳过（兼容本地/e2e）。
   - 内置 `fetch` + 8s 超时。

2. `server/src/config.ts`：新增 `developerApiBase`（默认 `https://developer.ssemarket.cn`）、`developerModuleSlug`（默认 `platform`）、`developerModulePrivateKey`。

3. `server/src/routes/usage.ts`：
   - `/by-user`：每个用户行附 `oauthId` + `dev`（`isDeveloper`/`isAdminDev`/`roleLabel`/`developerUserId`）；请求 `withDev=0` 可关闭。开发者平台失败不影响用量本体。
   - 新增 `GET /api/usage/by-user/:userId/reqs`（仅管理员）：按 api-platform userId → oauthId → check → reqs，返回 `{ isDeveloper, isAdmin, roleLabel, reqs, reqsError, configured }`。

4. `server/package.json`：新增依赖 `sm-crypto@^0.5.7`。

### 前端

- `web/src/api/index.ts`：新增 `usageUserReqs(userId)`。
- `web/src/views/AdminView.vue`：
  - 用户用量表格新增「角色」列，行内渲染 `role-chip` 徽标（`role-admin`/`role-dev`/`role-user`）。
  - 下钻明细顶部新增「集市开发者 + 需求单」卡片（`.ru-devbox`）：角色徽标 + 需求列表（阶段徽标 `stage-review`/`stage-dev`/`stage-deploy`、标题、所属业务、优先级、期望完成时间）。
  - 新增 `ruDevReqs` 状态与 `loadDevReqs`、`roleCls`、`priorityLabel`、`stageKey`、`fmtDate` 等辅助函数与样式。

### 环境 / 部署

- `deploy/oauth.env`（打进包内 `server/.env`）新增：
  - `DEVELOPER_API_BASE=https://developer.ssemarket.cn`
  - `DEVELOPER_MODULE_SLUG=platform`
  - `DEVELOPER_MODULE_PRIVATE_KEY=<set-in-server/.env>`
- `server/.env.example` 同步补充。

## 未决 / 注意

- 私钥写入了 `deploy/oauth.env` 与 `server/.env.example` 占位（生产需按环境注入，勿提交真实密钥到公开仓库）。
- 开放 API 需开发者平台侧为模块 `platform` 授权 `developers`、`reqs`（及 `reqs.userReqs`）scope，否则调用返回 403；本实现已做失败兜底（角色降级为普通用户、需求单显示错误）。
- `by-user` 默认对每个用户逐个调 `checkDeveloper`，用户数多时串行/并行请求开发者平台；超时 8s，失败不影响用量数据展示。如需可加 `withDev=0` 关闭或服务端缓存。
- 需求单接口 `pageSize=50`，仅返回进行中（不含已完成/归档）。
